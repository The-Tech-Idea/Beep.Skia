# Beep.Ski.Quantitative

Quantitative chart components (bar, line, pie, scatter, area) for Beep.Skia diagrams

| | |
|---|---|
| Target frameworks | `net8.0;net9.0` |
| NuGet package | `Beep.Ski.Quantitative` |
| Documentation | [quantitative.html](../Help/diagram-families/quantitative.html) |
| Start with | TimeSeriesNode, IndicatorNode, StrategyNodes |

Charts: bar, line, pie, scatter, area.

```bash
dotnet add package Beep.Ski.Quantitative
```

## Building

```bash
dotnet build Beep.Ski.Quantitative/Beep.Ski.Quantitative.csproj
```

The solution requires the private `TheTechIdea.Beep.*` NuGet feed; see [CONTRIBUTING.md](../CONTRIBUTING.md).
