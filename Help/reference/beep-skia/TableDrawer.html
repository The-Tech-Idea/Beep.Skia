Partial class for TableDrawer containing all mouse interaction methods

Members

MemberKindDescription
void HandleMouseDown(SKPoint mouseLocation)MethodHandles mouse down events to initiate drag operations on table cells. The location of the mouse pointer when the button was pressed.
void HandleMouseMove(SKPoint mouseLocation)MethodHandles mouse move events to update the position of dragged cells. The current location of the mouse pointer.
void HandleMouseUp(SKPoint mouseLocation)MethodHandles mouse up events to complete drag operations and potentially swap cell positions. The location of the mouse pointer when the button was released.
