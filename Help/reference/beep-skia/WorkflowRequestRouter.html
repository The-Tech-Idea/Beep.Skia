WorkflowRequestRouter class

Beep.Skia (core) — class

Maps HTTP routes onto WorkflowExecutionApi. Adapters (HttpListener, ASP.NET, Azure Functions) only need to translate their request/response types. Routes: GET /health → service status GET /api/workflows → published workflows POST /api/workflows?name=... → publish a diagram DTO (body) as a workflow GET /api/jobs?state=&amp;limit= → list jobs POST /api/jobs?workflowId=&amp;submittedBy= → submit a job (body = inputs JSON object) GET /api/jobs/{id} → job detail POST /api/jobs/{id}/cancel → cancel a job POST /api/jobs/{id}/pause → pause a job POST /api/jobs/{id}/resume → resume a job
