WorkflowExecutionService class

Beep.Skia (core) — class

Transport-agnostic execution service for published workflows: submit jobs with inputs, queue them with bounded concurrency, query status, pause/resume/cancel, and inspect results. A REST layer (or any other transport) can be placed on top of this service.
