ExtensionPackageManager class

Beep.Skia (core) — class

Installs, updates, and uninstalls extension packages. Packages are extracted to installRoot/&lt;id&gt;/&lt;version&gt;; the active version of each extension is tracked in installed.json. Extract paths are validated against zip-slip entries.
