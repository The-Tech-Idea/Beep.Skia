WorkflowEngine class

Beep.Skia (core) — class

Basic implementation of IWorkflowEngine that executes automation node graphs. Traverses nodes in dependency order (topological sort via connection lines), calling each IAutomationNode's InitializeAsync/ValidateAsync/ExecuteAsync in sequence.
