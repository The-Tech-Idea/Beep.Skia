ThemeManager class

Beep.Skia (core) — class

Central theme manager that controls the active theme across all diagram components. Components read theme tokens from ThemeManager.Current.

Members

MemberKindDescription
static SkiaTheme CurrentPropertyGets or sets the current active theme. Setting this fires ThemeChanged.
static event EventHandler ThemeChangedPropertyFires when the active theme changes. Components subscribe to redraw.
static void ApplyTheme(string name)MethodApplies a named theme. Built-in names: Light, Dark, HighContrast, Nord, Dracula.
static IReadOnlyList<string> BuiltInThemesPropertyGets a list of built-in theme names.
