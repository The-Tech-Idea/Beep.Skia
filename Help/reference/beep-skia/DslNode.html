DslNode class

Beep.Skia (core) — class

A parsed DSL node with layout geometry.

Quick usage

var component = new DslNode { X = 100, Y = 100, Width = 160, Height = 60 };
component.Title = "Example";
drawingManager.AddComponent(component);
drawingManager.RequestRedraw();
