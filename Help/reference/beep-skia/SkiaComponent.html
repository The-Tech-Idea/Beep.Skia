SkiaComponent class

Beep.Skia (core) — class

Base class for all Skia components in the framework. Provides common functionality for positioning, sizing, rendering, and interaction.

Quick usage

var component = new SkiaComponent { X = 100, Y = 100, Width = 160, Height = 60 };
component.DisplayText = "Example";
drawingManager.AddComponent(component);
drawingManager.RequestRedraw();
