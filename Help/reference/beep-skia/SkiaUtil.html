SkiaUtil class

Beep.Skia (core) — class

Provides utility methods for SkiaSharp operations including geometric transformations, color space conversions, and mathematical calculations.

Members

MemberKindDescription
static SKPoint Rotate(SKPoint point, float degrees)MethodRotates a point around the origin by the specified number of degrees. The point to rotate. The rotation angle in degrees. The rotated point.
static SKPoint Add(SKPoint point1, SKPoint point2)MethodAdds two points together component-wise. The first point. The second point. The sum of the two points.
static SKPoint Subtract(SKPoint point1, SKPoint point2)MethodSubtracts the second point from the first point component-wise. The first point. The second point to subtract. The difference between the two points.
static float CrossProduct(SKPoint v1, SKPoint v2)MethodCalculates the cross product (also known as the z-component of the 3D cross product) of two 2D vectors. The first vector. The second vector. The cross product value.
static (float Hue, float Saturation, float Luminosity) ToHsl(this SKColor color)MethodConverts an SKColor to HSL (Hue, Saturation, Luminosity) color space. The SKColor to convert. A tuple containing Hue (0-360), Saturation (0-1), and Luminosity (0-1).
static SKColor FromHsl(float hue, float saturation, float luminosity)MethodCreates an SKColor from HSL (Hue, Saturation, Luminosity) values. The hue component (0-360 degrees). The saturation component (0-1). The luminosity component (0-1). The corresponding SKColor.
