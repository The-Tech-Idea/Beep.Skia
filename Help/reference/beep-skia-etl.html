ExpressionEngine (class)

Small SQL-like expression engine for ETL derived columns, conditional splits, filters, and custom data-quality rules. Supports: literals (number/string/TRUE/FALSE/NULL), column references ([Column], "Column", `Column`, or bare identifiers), arithmetic (+ - * / %), comparisons (= == != &lt;&gt; &lt; &lt;= &gt; &gt;=), logical operators (AND OR NOT), IS NULL / IS NOT NULL, LIKE, and a built-in function library. Unknown columns evaluate to null.

MemberKindDescription
static IReadOnlyCollection<string> FunctionsPropertyGets the names of all built-in functions.
object Evaluate(string expression, IDictionary<string, object> row)MethodEvaluates an expression against a row. Returns null when the result is NULL.
bool EvaluateBoolean(string expression, IDictionary<string, object> row)MethodEvaluates an expression as a boolean (null/0/empty/"false" are false).
IReadOnlyCollection<string> GetReferencedColumns(string expression)MethodReturns the column names referenced by the expression (excluding function names).

StructuredDataFlattener (class)

Flattens structured JSON/XML into tabular rows (dictionaries) for ETL processing, and infers a tabular schema from flattened rows. Nested objects become dot-separated columns (address.city); arrays are preserved as JSON text so no data is lost; XML attributes become "@name" columns.

MemberKindDescription
List<Dictionary<string, object>> FlattenJson(string json, string rootPath = null, FlattenOptions options = null)MethodFlattens a JSON document into rows. JSON text. Optional dot path to the array/object to flatten (e.g., "data.items"). Flattening options.
List<Dictionary<string, object>> FlattenXml(string xml, string rowElement = null, FlattenOptions options = null)MethodFlattens an XML document into rows. When is null, the most frequent child element of the root is used as the row element.
List<ColumnDefinition> InferSchema(IEnumerable<IDictionary<string, object>> rows, string stringType = "VARCHAR")MethodInfers a tabular schema from flattened rows. Numeric columns merge to FLOAT, mixed types fall back to STRING, and sparse/missing values mark the column nullable.
