BeepSkiaLoaderExtensions (class)

BeepDM loader extension that discovers Skia components in loaded assemblies. The extension subscribes to the process-wide AssemblyResolve event, so it must be disposed when the host is done with it; otherwise the instance stays alive and its resolution logic runs for every assembly load in the process.
