DFDLevelNavigator (class)

Manages drill-down navigation across DFD decomposition levels. The caller captures the current diagram as a DiagramDto before drilling in, and restores frames when navigating up.

MemberKindDescription
DFDLevelFrame? CurrentPropertyGets the currently displayed level.
bool CanGoUpPropertyGets a value indicating whether there is a parent level to return to.
int DepthPropertyGets the current decomposition depth (0 = top level).
string BreadcrumbPropertyGets a breadcrumb like "Level 0 &gt; Process 1 &gt; Process 1.1".
void Reset(DiagramDto? rootDiagram = null)MethodResets navigation to the top-level diagram.
bool DrillDown(string processName, DiagramDto currentDiagram, DiagramDto childDiagram)MethodDrills into a process's child decomposition diagram. Display name of the process being decomposed. Live snapshot of the currently displayed diagram (pushed as the parent frame). The child diagram to display. True when the drill-down started.
DFDLevelFrame? GoUp()MethodReturns to the parent level. The frame now displayed, or null when already at the top level.
