IntermediateEventNode class

Business process (BPMN) family — class

BPMN 2.0 Intermediate Event node. Rendered as a double-ring circle with event type icon inside the inner ring. Supports Catch (incoming flow triggers event) and Throw (event triggers outgoing flow) semantics.
