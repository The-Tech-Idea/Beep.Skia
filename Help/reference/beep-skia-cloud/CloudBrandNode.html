CloudBrandNode class

Cloud architecture family — class

Base class for provider-branded cloud service nodes (AWS / Azure / GCP). Renders a brand-colored accent bar, a glyph badge, the service name, and the provider.

Members

MemberKindDescription
abstract string ProviderPropertyCloud provider name (AWS, Azure, GCP).
abstract string ServiceNamePropertyService name (EC2, Blob Storage, ...).
abstract SKColor BrandColorPropertyProvider brand color used for the accent bar and badge.
virtual string IconGlyphPropertyShort glyph shown inside the badge (defaults to the service name).
