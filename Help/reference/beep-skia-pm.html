CriticalPathCalculator (class)

Calculates the critical path for a project network diagram. Uses forward/backward pass to compute early/late dates and float (slack).

MemberKindDescription
List<TaskSchedule> SchedulesPropertyGets or sets the schedules.
int ProjectDurationPropertyGets or sets the project duration.
List<TaskNode> CriticalPathPropertyGets or sets the critical path.
void Calculate(IReadOnlyList<SkiaComponent> components, IReadOnlyList<IConnectionLine> lines)MethodComputes the schedule from components and connection lines. Lines represent FS (Finish-to-Start) dependencies by default. DependencyNode with LagDays adjusts the dependency timing.
