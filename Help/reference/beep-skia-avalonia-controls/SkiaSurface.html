SkiaSurface class

Avalonia controls — class

Avalonia control that renders Beep.Skia diagrams. SkiaSharp ships no Avalonia view package, so this control renders into an offscreen SKSurface backed by the memory of an Avalonia WriteableBitmap (BGRA8888, premultiplied) and blits it. It therefore depends only on Avalonia + SkiaSharp and works with the same SkiaSharp version as the rest of the solution.
