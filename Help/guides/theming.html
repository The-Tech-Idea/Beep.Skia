Theming Guide

Material Design 3.0 theming, custom color tokens, and visual customization

Beep.Skia implements a comprehensive Material Design 3.0 theming system modeled after the Material You design language. Every visual component — from diagram nodes to UI controls — resolves its colors through a centralized token system that supports light, dark, and custom themes.

Material Design 3.0 Tokens

The theme system is built on a set of named color tokens that propagate through the component tree. Each token represents a semantic role in the UI, not a specific hex color. Tokens are resolved at render time based on the current theme, dark/light mode, and component-level overrides.

Core Color Tokens

TokenRoleLight Theme DefaultDark Theme Default
PrimaryBrand color, primary actions, active states #6750A4 #D0BCFF
OnPrimaryText/icons on primary-colored surfaces #FFFFFF #381E72

OnSurfacePrimary text and iconography on surfaces #1C1B1F #E6E1E5

OutlineBorders, dividers, and structural lines #79747E #938F99

Token Propagation

Tokens flow through the component tree via MaterialControl. Each component inherits the theme from its parent DrawingManager unless explicitly overridden:

Token Resolution Chain

// 1. DrawingManager holds the active MaterialDesignTheme
var theme = drawingManager.Theme;

// 2. Each MaterialControl resolves tokens through the chain:
//    Control override > Parent theme > DrawingManager theme > Default theme
public SKColor PrimaryColor => _primaryOverride ?? Parent?.PrimaryColor
    ?? DrawingManager?.Theme?.Primary ?? MaterialDesignColors.Default.Primary;

public SKColor SurfaceColor => _surfaceOverride ?? Parent?.SurfaceColor
    ?? DrawingManager?.Theme?.Surface ?? MaterialDesignColors.Default.Surface;

public SKColor OutlineColor => _outlineOverride ?? Parent?.OutlineColor
    ?? DrawingManager?.Theme?.Outline ?? MaterialDesignColors.Default.Outline;

This resolution chain means you can change the entire application theme by assigning a new MaterialDesignTheme to the DrawingManager, and all 5,000 components instantly reflect the new colors on the next frame.

Applying a Color Preset

// Apply a built-in preset
drawingManager.Theme = MaterialDesignColors.Blue;

// Toggle dark/light mode
drawingManager.Theme.Mode = ThemeMode.Dark;

// Create a custom preset from a seed color (Material You style)
var customTheme = MaterialDesignColors.FromSeed(SKColors.Coral);
drawingManager.Theme = customTheme;

Custom Themes

Per-Component Color Overrides

Any MaterialControl can override individual color tokens without affecting siblings or children:

Component-Level Token Override

public class CriticalNode : FlowChartNode
{
    public CriticalNode()
    {
        // Override just the primary color for this specific node
        OverridePrimary(SKColors.Red);

        // Override the surface (background) color
        OverrideSurface(new SKColor(0xFF, 0xF0, 0xF0));

        // Override outline color
        OverrideOutline(new SKColor(0xCC, 0x00, 0x00));
    }
}

Per-Family Theme Overrides

Set theme overrides at the family base-class level to give an entire diagram family a distinctive look:

Family-Level Theming

public abstract class SecurityNodeBase : MaterialControl
{
    protected override void Initialize()
    {
        base.Initialize();

        // All security diagram nodes get a dark, high-contrast theme
        OverrideSurface(new SKColor(0x1A, 0x1A, 0x2E));
        OverrideOnSurface(new SKColor(0xE0, 0xE0, 0xFF));
        OverridePrimary(new SKColor(0x00, 0xFF, 0x88));
        OverrideOutline(new SKColor(0x44, 0x44, 0x66));
    }
}

Dynamic Theme Switching

Themes can be changed at runtime without disrupting the user's diagram. The DrawingManager handles theme changes by invalidating all components:

Runtime Theme Toggle

public void ToggleDarkMode()
{
    var theme = drawingManager.Theme;

    if (theme.Mode == ThemeMode.Light)
    {
        theme.Mode = ThemeMode.Dark;
    }
    else
    {
        theme.Mode = ThemeMode.Light;
    }

    // Theme change invalidates all components automatically
    drawingManager.InvalidateAll();

    // Alternative: switch to a completely different theme
    drawingManager.Theme = userPreferences.UseHighContrast
        ? MaterialDesignColors.HighContrast
        : MaterialDesignColors.Purple;
}

Theme Persistence

Theme settings (preset name and mode) are serialized as part of the diagram document. When a user saves a diagram with a custom theme and reopens it, the theme is restored automatically. To opt out, set DrawingManager.PersistTheme = false and manage theme state at the application level.

Shadows & Elevation

Material Design defines 6 elevation levels (0–5), each producing a different shadow rendering on MaterialControl subclasses. Shadows are rendered using SKImageFilter.CreateDropShadow() and cached per elevation level.

Elevation Levels

LevelOffset YBlurOpacityUse Case
00px0px0%Flat components: labels, text nodes
11px3px12%Standard nodes, buttons, inputs
22px6px16%Cards, panels, selected components
34px8px19%Floating toolbars, modal dialogs
46px12px24%Menus, dropdowns, popovers
58px16px28%Dialogs, notifications, alerts

Shadow Rendering

protected override void DrawBackgroundContent(SKCanvas canvas)
{
    if (Elevation > 0)
    {
        // Shadow is rendered first, offset by elevation parameters
        var shadowFilter = SKImageFilter.CreateDropShadow(
            0f,                                  // dx
            Elevation * 2f,                      // dy (proportional to elevation)
            Elevation * 2f,                      // sigmaX (blur)
            Elevation * 2f,                      // sigmaY (blur)
            new SKColor(0, 0, 0, (byte)(Elevation * 30)),  // opacity scales with elevation
            null                                 // no crop rect
        );

        using var shadowPaint = new SKPaint
        {
            IsAntialias = true,
            ImageFilter = shadowFilter,
            Style = SKPaintStyle.Fill,
            Color = SurfaceColor
        };

        canvas.DrawRoundRect(GetContentRect(), CornerRadius, CornerRadius, shadowPaint);
    }
    // ... then draw the actual component on top ...
}

Performance Note

Drop shadows are computed per-component on the CPU via SkiaSharp. On large diagrams (>500 components), consider disabling shadows (Elevation = 0) globally with drawingManager.EnableShadows = false. The default theme uses elevation 1 for most components, which is a good balance between visual depth and performance.

Complete Theming Example: Custom Dark Theme Application

Applying a Complete Custom Theme

public void ApplyCorporateDarkTheme(DrawingManager drawingManager)
{
    var theme = new MaterialDesignTheme
    {
        Name = "Corporate Dark",
        Mode = ThemeMode.Dark,
        LightScheme = MaterialDesignColors.Purple.LightScheme,
        DarkScheme = new ColorScheme
        {
            Primary = new SKColor(0x7B, 0xA4, 0xFF),
            OnPrimary = new SKColor(0x00, 0x1A, 0x40),
            PrimaryContainer = new SKColor(0x00, 0x2D, 0x6D),
            Secondary = new SKColor(0x90, 0xCA, 0xF1),
            Surface = new SKColor(0x0D, 0x0E, 0x13),
            OnSurface = new SKColor(0xE2, 0xE2, 0xE9),
            SurfaceVariant = new SKColor(0x2A, 0x2B, 0x33),
            Outline = new SKColor(0x6B, 0x6D, 0x7B),
            Error = new SKColor(0xFF, 0xB4, 0xAB)
        }
    };

    drawingManager.Theme = theme;
    drawingManager.EnableShadows = true;
    drawingManager.DefaultElevation = 1;

    // Set default typography
    drawingManager.DefaultFontFamily = "Inter";
    drawingManager.DefaultFontSize = 14f;
    drawingManager.DefaultBorderStyle = BorderStyle.Solid;
    drawingManager.DefaultBorderWidth = 1.5f;

    // Apply globally
    drawingManager.InvalidateAll();
}
