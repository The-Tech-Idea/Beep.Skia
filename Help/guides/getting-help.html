Getting Help

Where to look when something does not work as expected

Start with the symptom, not the technology: most problems are answered by one of the pages below, and the rest have a clear reporting path.

In the Application

  • Help menu — the WinForms sample has a Help dropdown with Documentation, Quick Start, Sample Applications, Troubleshooting, API Reference and About.
  • F1 — opens the documentation site from the app (falls back to the repository README when the Help folder is not next to the executable).
  • Status bar — reports the result of every command (validation summaries, workflow status, export paths).
  • Tooltips — toolbar buttons and palette items describe their action.

From the Code

  • IntelliSense — every package ships XML documentation, so member summaries and parameter descriptions appear in the IDE (97% of the public surface is documented).
  • Diagnostics — the rendering pipeline catches per-component exceptions and writes them to the debug trace; check the Output window when a component misbehaves.
  • Validation — run DiagramValidator (or the sample's Validate command) to get rule-based feedback with fix suggestions.
  • Job results — workflow failures carry the failing node, error message and per-node status in WorkflowResult.

Reporting a Problem

  1. Check Troubleshooting first — restore, TFM, port-layout, drop-offset, serialization and automation issues are covered there.
  2. Search the issue tracker for the same symptom.
  3. Open an issue with: package and version (Beep.Skia version from the NuGet package or the assembly version), target framework, a minimal reproduction (a few lines that build a diagram or run a workflow), expected vs. actual behaviour, and the full exception text if there is one.
  4. For security problems, do not open a public issue — follow SECURITY.md.

Faster reproductions

A diagram that reproduces the issue can be attached as JSON: drawingManager.ToDto() serialized with System.Text.Json is the complete state (components, properties, connections, theme).
