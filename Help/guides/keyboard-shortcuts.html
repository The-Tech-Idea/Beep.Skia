Keyboard and Mouse

Every shortcut the canvas handles out of the box

DrawingManager.HandleKeyDown(keyCode, modifiers) implements the standard editor shortcuts, and the host control routes mouse input to HandleMouseDown/Move/Up/Wheel in world coordinates. This page is the complete reference.

Host Integration

The manager handles keys; the host forwards them. In WinForms that is a single call per key, with modifiers mapped to SKKeyModifiers:

int mods = 0;
if (e.Control) mods |= 1;
if (e.Shift)   mods |= 2;
if (e.Alt)     mods |= 4;

if (drawingManager.HandleKeyDown((int)e.KeyCode, mods))
{
    e.Handled = true;          // the manager consumed the key
    e.SuppressKeyPress = true;
}

HandleKeyDown returns true when it acted on the key, so hosts can keep their own shortcuts (F1, menus, save dialogs) by handling them first. To rebind a shortcut, intercept the key in the host and call the corresponding manager API instead.
