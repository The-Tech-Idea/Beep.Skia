Creating Custom Diagram Families

Step-by-step guide to building your own domain-specific diagram family

Beep.Skia ships with 18 built-in diagram families covering business processes, data modeling, engineering, and analytics. When your domain requires visual representations not covered by the built-in families, you can create a custom diagram family that plugs directly into the Skia rendering pipeline, the component palette, and the serialization system.

Overview

Every diagram family in Beep.Skia follows the same architectural pattern:

IDrawableComponent
↓
SkiaComponent
Position, size, NodeProperties, ConnectionPoints
↓
MaterialControl
Material Design 3.0 theming, elevation, state layers
↓
FamilyBaseControl
Your custom base class — shared rendering, ports, behavior
↓
Concrete Node Classes
ValveNode, PumpNode, TankNode, PipeNode, etc.

Each family lives in its own .csproj project, typically named Beep.Skia.Chart.<FamilyName>. This isolation allows families to be loaded independently via the AssemblyHandler plugin system, keeping application startup lean and enabling NuGet distribution.

Step 2: Create the Base Control

The base control is the heart of your diagram family. It inherits from MaterialControl and provides shared rendering, port management, and property defaults for all concrete nodes in the family.

Your base class should override these key template methods:

MethodPurposeOverride?
DrawContent(SKCanvas)Core visual rendering of the nodeUsually in concrete classes, shared logic here
DrawBackgroundContent(SKCanvas)Background fill, shadow, border before foregroundYes — family-specific shape
DrawForegroundContent(SKCanvas)Text labels, icons, overlays after backgroundYes — family-specific text/icons
DrawSelectionContent(SKCanvas)Selection highlight and resize handlesOptional — falls back to default
EnsurePortLayout()Recompute port positionsYes — define where ports appear
Initialize()Set up paints, NodeProperties, default sizeYes — call base.Initialize()

Base Control: PnIDNodeBase.cs

using Beep.Skia;
using SkiaSharp;

namespace Beep.Skia.Chart.PnID.Nodes;

public abstract class PnIDNodeBase : MaterialControl
{
    protected SKPaint FillPaint { get; set; }
    protected SKPaint StrokePaint { get; set; }
    protected SKPaint TextPaint { get; set; }
    protected string NodeLabel { get; set; } = "";

    protected override void Initialize()
    {
        base.Initialize();

        Width = 80f;
        Height = 80f;

        FillPaint = new SKPaint
        {
            Style = SKPaintStyle.Fill,
            IsAntialias = true,
            Color = SurfaceColor
        };

        StrokePaint = new SKPaint
        {
            Style = SKPaintStyle.Stroke,
            IsAntialias = true,
            StrokeWidth = 2f,
            Color = OutlineColor
        };

        TextPaint = new SKPaint
        {
            IsAntialias = true,
            TextSize = 11f,
            TextAlign = SKTextAlign.Center,
            Color = OnSurfaceColor
        };

        NodeProperties["Label"] = new ParameterInfo
        {
            Name = "Label",
            DisplayName = "Label",
            Value = "",
            DataType = typeof(string),
            Category = "Content",
            EditorHint = "TextBox"
        };

        NodeProperties["EquipmentTag"] = new ParameterInfo
        {
            Name = "EquipmentTag",
            DisplayName = "Equipment Tag",
            Value = "V-001",
            DataType = typeof(string),
            Category = "Engineering",
            EditorHint = "TextBox"
        };
    }

    protected override void EnsurePortLayout()
    {
        if (!PortsDirty) return;

        InPoints.Clear();
        OutPoints.Clear();

        float cx = X + Width / 2;
        float cy = Y + Height / 2;

        // Input ports: left and top
        InPoints.Add(new ConnectionPoint
        {
            Type = PortType.In,
            Position = new SKPoint(X, cy),
            DataType = typeof(object),
            Owner = this
        });

        InPoints.Add(new ConnectionPoint
        {
            Type = PortType.In,
            Position = new SKPoint(cx, Y),
            DataType = typeof(object),
            Owner = this
        });

        // Output ports: right and bottom
        OutPoints.Add(new ConnectionPoint
        {
            Type = PortType.Out,
            Position = new SKPoint(X + Width, cy),
            DataType = typeof(object),
            Owner = this
        });

        OutPoints.Add(new ConnectionPoint
        {
            Type = PortType.Out,
            Position = new SKPoint(cx, Y + Height),
            DataType = typeof(object),
            Owner = this
        });

        MarkPortsClean();
    }

    protected override void DrawBackgroundContent(SKCanvas canvas)
    {
        var rect = new SKRect(X, Y, X + Width, Y + Height);
        canvas.DrawRoundRect(rect, 4f, 4f, FillPaint);
        canvas.DrawRoundRect(rect, 4f, 4f, StrokePaint);
    }

    protected override void DrawForegroundContent(SKCanvas canvas)
    {
        if (string.IsNullOrEmpty(NodeLabel)) return;

        float textY = Y + Height / 2 + TextPaint.TextSize / 3;
        canvas.DrawText(NodeLabel, X + Width / 2, textY, TextPaint);
    }

    public override void Dispose()
    {
        FillPaint?.Dispose();
        StrokePaint?.Dispose();
        TextPaint?.Dispose();
        base.Dispose();
    }
}

Port Management Best Practice

Always guard EnsurePortLayout() with a PortsDirty check and call MarkPortsClean() after recomputing positions. Override MarkPortsDirty() to set your dirty flag and call base.MarkPortsDirty(). This lazy-evaluation pattern avoids recomputing port geometry on every frame during drag operations.

Step 3: Create Node Classes

Concrete node classes inherit from your base control and implement the family-specific visual representation and DrawContent() method. Each node type should define its own default size, visual shape, and port layout.

Concrete Node: ValveNode.cs

using SkiaSharp;

namespace Beep.Skia.Chart.PnID.Nodes;

public class ValveNode : PnIDNodeBase
{
    public ValveNode() : base()
    {
        NodeLabel = "Valve";
        Width = 60f;
        Height = 80f;
    }

    public override void DrawContent(SKCanvas canvas)
    {
        DrawBackgroundContent(canvas);

        // Draw valve-specific shape: bowtie
        float cx = X + Width / 2;
        float cy = Y + Height / 2;
        float hw = Width / 2;
        float hh = Height / 2;

        using var path = new SKPath();
        path.MoveTo(cx, Y);           // top center
        path.LineTo(X + Width, cy);   // right center
        path.LineTo(cx, Y + Height);  // bottom center
        path.LineTo(X, cy);           // left center
        path.Close();

        canvas.DrawPath(path, FillPaint);
        canvas.DrawPath(path, StrokePaint);

        DrawForegroundContent(canvas);
    }
}

Concrete Node: PumpNode.cs

using SkiaSharp;

namespace Beep.Skia.Chart.PnID.Nodes;

public class PumpNode : PnIDNodeBase
{
    public PumpNode() : base()
    {
        NodeLabel = "Pump";
        Width = 70f;
        Height = 70f;
    }

    public override void DrawContent(SKCanvas canvas)
    {
        DrawBackgroundContent(canvas);

        float cx = X + Width / 2;
        float cy = Y + Height / 2;
        float radius = Math.Min(Width, Height) / 2 - 4f;

        // Draw circle
        canvas.DrawCircle(cx, cy, radius, FillPaint);
        canvas.DrawCircle(cx, cy, radius, StrokePaint);

        // Draw pump triangle inside
        using var trianglePath = new SKPath();
        float r = radius * 0.5f;
        trianglePath.MoveTo(cx + r, cy);
        trianglePath.LineTo(cx - r * 0.5f, cy - r * 0.866f);
        trianglePath.LineTo(cx - r * 0.5f, cy + r * 0.866f);
        trianglePath.Close();

        using var trianglePaint = new SKPaint
        {
            Style = SKPaintStyle.Fill,
            IsAntialias = true,
            Color = OutlineColor
        };
        canvas.DrawPath(trianglePath, trianglePaint);

        DrawForegroundContent(canvas);
    }
}

Concrete Node: TankNode.cs

using SkiaSharp;

namespace Beep.Skia.Chart.PnID.Nodes;

public class TankNode : PnIDNodeBase
{
    public TankNode() : base()
    {
        NodeLabel = "Tank";
        Width = 100f;
        Height = 120f;
    }

    public override void DrawContent(SKCanvas canvas)
    {
        DrawBackgroundContent(canvas);

        float bx = X + 4f;
        float bw = Width - 8f;
        float topSection = Y + Height * 0.15f;
        float bottomSection = Y + Height * 0.85f;

        using var path = new SKPath();

        // Tank body (rectangle with rounded bottom)
        path.MoveTo(bx, topSection);
        path.LineTo(bx, bottomSection);

        // Bottom arc
        var bottomRect = new SKRect(bx, bottomSection - bw / 2, bx + bw, bottomSection + bw / 2);
        path.ArcTo(bottomRect, 180f, 180f, false);

        path.LineTo(bx + bw, topSection);
        path.Close();

        canvas.DrawPath(path, FillPaint);
        canvas.DrawPath(path, StrokePaint);

        // Top rim
        canvas.DrawLine(bx - 4f, topSection, bx + bw + 4f, topSection, StrokePaint);

        DrawForegroundContent(canvas);
    }
}

Concrete Node: PipeNode.cs

using SkiaSharp;

namespace Beep.Skia.Chart.PnID.Nodes;

public class PipeNode : PnIDNodeBase
{
    public float PipeDiameter { get; set; } = 8f;

    public PipeNode() : base()
    {
        NodeLabel = "Pipe";
        Width = 120f;
        Height = PipeDiameter + 4f;
    }

    public override void DrawContent(SKCanvas canvas)
    {
        float midY = Y + Height / 2;
        float startX = X + 4f;
        float endX = X + Width - 4f;

        using var thickPaint = new SKPaint
        {
            Style = SKPaintStyle.Stroke,
            StrokeWidth = PipeDiameter,
            IsAntialias = true,
            Color = OutlineColor,
            StrokeCap = SKStrokeCap.Round
        };

        canvas.DrawLine(startX, midY, endX, midY, thickPaint);

        // Flow direction arrow
        float arrowX = X + Width * 0.65f;
        using var arrowPaint = new SKPaint
        {
            Style = SKPaintStyle.Fill,
            IsAntialias = true,
            Color = OnSurfaceColor
        };

        using var arrowPath = new SKPath();
        arrowPath.MoveTo(arrowX + 8f, midY);
        arrowPath.LineTo(arrowX - 4f, midY - 6f);
        arrowPath.LineTo(arrowX - 4f, midY + 6f);
        arrowPath.Close();
        canvas.DrawPath(arrowPath, arrowPaint);

        DrawForegroundContent(canvas);
    }
}

Step 4: Register with SkiaComponentRegistry

Use the [AddinAttribute] to mark your assembly for automatic discovery by the AssemblyHandler and SkiaComponentRegistry. The registry scans all loaded assemblies for SkiaComponent subclasses and makes them available for palette integration and serialization.

Assembly-Level Registration

using Beep.Skia;

[assembly: Addin(
    Name = "Beep.Skia.Chart.PnID",
    Description = "Piping & Instrumentation Diagram family for process engineering",
    Version = "1.0.0",
    Category = "Engineering",
    Author = "Your Company",
    TargetFramework = "net8.0;net9.0"
)]

The SkiaComponentRegistry (661 lines of registration and discovery logic) uses reflection to find all types decorated with [AddinAttribute]. Once discovered, components are available for:

  • Palette Registration: Appear as draggable toolbox items in ComponentPalette
  • Serialization: Full type-name resolution for save/load round-trips
  • Dynamic Instantiation: Activator.CreateInstance() with type safety via the registry
  • NuGet Loading: Types resolved from NuGet packages are registered automatically upon load

Manual Registration (when not using AddinAttribute)

var registry = SkiaComponentRegistry.Instance;

registry.RegisterComponent<ValveNode>("P&ID", "Valve");
registry.RegisterComponent<PumpNode>("P&ID", "Pump");
registry.RegisterComponent<TankNode>("P&ID", "Tank");
registry.RegisterComponent<PipeNode>("P&ID", "Pipe");

Type Resolution

The registry resolves component types by their fully-qualified assembly name during deserialization. Ensure your assembly name and type names are stable across versions. Avoid renaming node classes in released versions without providing a type-migration map.

Step 5: Add to ComponentPalette

The ComponentPalette is the visual toolbox that users drag-and-drop from to create diagram elements. After registering with the SkiaComponentRegistry, create a palette provider to define how your components appear in the toolbox.

Palette Provider: PnIDPaletteProvider.cs

using Beep.Skia.UI;

namespace Beep.Skia.Chart.PnID.Palette;

public class PnIDPaletteProvider : IPaletteProvider
{
    public string CategoryName => "Piping & Instrumentation";
    public string CategoryIcon => "bi bi-droplet";
    public int DisplayOrder => 25;

    public IEnumerable<PaletteItem> GetPaletteItems()
    {
        yield return new PaletteItem
        {
            DisplayName = "Valve",
            ComponentType = typeof(ValveNode),
            IconGlyph = "⬤",
            Tooltip = "Control valve (gate, globe, ball, butterfly)",
            DefaultWidth = 60f,
            DefaultHeight = 80f
        };

        yield return new PaletteItem
        {
            DisplayName = "Pump",
            ComponentType = typeof(PumpNode),
            IconGlyph = "◯",
            Tooltip = "Centrifugal or positive-displacement pump",
            DefaultWidth = 70f,
            DefaultHeight = 70f
        };

        yield return new PaletteItem
        {
            DisplayName = "Tank",
            ComponentType = typeof(TankNode),
            IconGlyph = "△",
            Tooltip = "Storage tank or pressure vessel",
            DefaultWidth = 100f,
            DefaultHeight = 120f
        };

        yield return new PaletteItem
        {
            DisplayName = "Pipe",
            ComponentType = typeof(PipeNode),
            IconGlyph = "━",
            Tooltip = "Process pipe with flow direction",
            DefaultWidth = 120f,
            DefaultHeight = 12f
        };
    }
}

Register the provider with ComponentPalette:

Registering the Palette Provider

var palette = new ComponentPalette();
palette.RegisterProvider(new PnIDPaletteProvider());

// The palette now shows "Piping & Instrumentation" as a category
// with Valve, Pump, Tank, and Pipe as draggable items.

Palette Organization

Group related node types under a single IPaletteProvider to create a collapsible category in the toolbox. Use DisplayOrder to control category ordering. Categories appear sorted ascending by DisplayOrder, then alphabetically by CategoryName.

Complete Example: P&ID Diagram Family

The following table summarizes the full Piping & Instrumentation Diagram (P&ID) family we just built. This family enables process engineers to create instrumentation diagrams with standard ISA S5.1 symbols:

ComponentClassShapePortsUse Case
ValveValveNodeBowtie (two opposing triangles)2 in (left, top), 2 out (right, bottom)Control valves, isolation valves, check valves
PumpPumpNodeCircle with direction triangle2 in (left, top), 2 out (right, bottom)Centrifugal pumps, positive-displacement pumps
TankTankNodeRectangular body with rounded bottom2 in (left, top), 2 out (right, bottom)Storage tanks, pressure vessels, reactors
PipePipeNodeHorizontal line with direction arrow1 in (left), 1 out (right)Process piping, flow direction indicators

With these four node types, a process engineer can compose complete P&ID diagrams by connecting pipes between equipment nodes, creating a directed graph that represents material flow through a process plant.

Extending the Family

This example shows the minimum viable product. A production P&ID family would include additional nodes (heat exchangers, compressors, distillation columns, instruments) and custom connection validation rules (e.g., pipes can only connect valves to tanks, not valves to valves). See Extensibility & Plugins for advanced extension patterns.

Serialization Support

Your family automatically supports serialization because all nodes extend SkiaComponent, which implements IDrawableComponent. The SkiaComponentRegistry handles type name resolution, and the DrawingManager serializer saves and restores all component properties, connections, and positions. No additional code is required — just ensure your NodeProperties are populated in Initialize() and that you call base.Initialize().

Smoke Test

[Test]
public void PnIDFamily_RenderSmokeTest()
{
    var surface = SKSurface.Create(new SKImageInfo(800, 600));
    var canvas = surface.Canvas;

    var nodes = new PnIDNodeBase[]
    {
        new TankNode { X = 50, Y = 200, NodeLabel = "TK-101" },
        new PumpNode { X = 250, Y = 220 },
        new ValveNode { X = 420, Y = 200 },
        new PipeNode { X = 160, Y = 235 }
    };

    foreach (var node in nodes)
    {
        node.Initialize();
        node.DrawContent(canvas);
        node.Dispose();
    }

    // Verify surface has non-empty pixels
    using var image = surface.Snapshot();
    Assert.That(image.Width, Is.EqualTo(800));
    Assert.That(image.Height, Is.EqualTo(600));

    surface.Dispose();
}
