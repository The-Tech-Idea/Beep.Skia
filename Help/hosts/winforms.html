WinForms Controls

The SkiaHostControl canvas host plus a WinForms wrapper for every Material control

The WinForms package ships two layers: SkiaHostControl, the full diagram editor surface (canvas, palette, property grid, export), and a wrapper control for every Material component so the same visuals can be used in ordinary WinForms layouts. All wrappers derive from SkiaControl.
