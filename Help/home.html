Overview

Beep.Skia is a comprehensive visual modeling toolkit built on SkiaSharp that provides a rich set of diagramming primitives, workflow automation components, and interactive canvas controls. Designed for .NET 8 and .NET 9, it enables developers to create complex 2D diagrams, flowcharts, network topologies, and custom visual editors with minimal effort.

The framework encompasses 18 distinct diagram families, over 200 specialized node types, and more than 60 reusable UI components across 17 modular projects. With built-in support for Material Design 3.0 theming, an extensible connection routing system, undo/redo history, and serialization, Beep.Skia serves as a foundation for building professional-grade visual tools in desktop, web, and mobile applications.

Core capabilities include a hardware-accelerated rendering pipeline via SkiaSharp, a flexible component model based on the SkiaComponent base class, drag-and-drop diagram construction, connection management with automatic pathfinding, and a workflow automation engine that integrates directly with the visual editor.

Quick Start

Install the core package via NuGet:

NuGet Installation

dotnet add package Beep.Skia

Basic Diagram with DrawingManager

using Beep.Skia;
using Beep.Skia.Canvas;
using Beep.Skia.Nodes;

var drawingManager = new DrawingManager();

var canvas = new SkiaCanvas(800, 600);
drawingManager.AttachCanvas(canvas);

var startNode = new FlowChartNode("Start");
startNode.Position = new SKPoint(100, 100);
drawingManager.AddNode(startNode);

var processNode = new FlowChartNode("Process");
processNode.Position = new SKPoint(400, 100);
drawingManager.AddNode(processNode);

drawingManager.Connect(startNode, processNode);
canvas.Invalidate();

Undo/Redo Full undo/redo stack for all diagram operations with granular command tracking
Serialization JSON and binary serialization for persisting and restoring complete diagram state
