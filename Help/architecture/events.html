Event Model

The event argument types raised by the manager, the interaction helper and the host

Beep.Skia reports activity through plain .NET events. The manager raises diagram-level events (ComponentDropped, DrawSurface, SelectionChanged and theme changes), while the interaction helper raises pointer and hover events. The event argument types below carry the payloads.

Drag and Drop Events

Payload raised when a component drag ends.

ComponentDropEventArgs

Event args for when a component is dropped after a drag operation. Provides final positions in canvas and screen space along with final bounds.

MemberKindDescription
SkiaComponent ComponentPropertyGets or sets the component.
SKPoint CanvasPositionPropertyGets or sets the canvas position.
SKPoint ScreenPositionPropertyGets or sets the screen position.
SKRect BoundsPropertyGets or sets the bounds.
SKPoint LocationPropertyGets or sets the location.
