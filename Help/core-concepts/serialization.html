Serialization Flow

The serialization system transforms the live diagram state into a portable JSON representation and back again. The process uses plain Data Transfer Objects (DTOs) serialized via System.Text.Json, ensuring no dependency on Newtonsoft.Json or binary formatters.

The DiagramDto is the root container:

public class DiagramDto
{

    public string DiagramType { get; set; }

    public DateTime ModifiedAt { get; set; }

}

Component Serialization

Each SkiaComponent on the canvas is serialized into a ComponentDto. The DTO captures the minimum information needed to reconstruct the component: its position, size, type identity, configurable properties, and connection-point GUIDs:

ComponentDto Structure

public class ComponentDto
{
    public Guid Id { get; set; }
    public string TypeName { get; set; }
    public float X { get; set; }
    public float Y { get; set; }
    public float Width { get; set; }
    public float Height { get; set; }
    public int ZOrder { get; set; }
    public bool IsVisible { get; set; } = true;

    public Dictionary<string, object> NodeProperties { get; set; } = new();

    public List<ConnectionPointDto> InPoints { get; set; } = new();
    public List<ConnectionPointDto> OutPoints { get; set; } = new();

    public string Tag { get; set; }
}

public class ConnectionPointDto
{
    public Guid Id { get; set; }
    public string PortType { get; set; }
    public string DataTypeName { get; set; }
    public string RowId { get; set; }
    public int MaxConnections { get; set; } = 1;
}

NodeProperties serialization converts the ParameterInfo dictionary into a flat Dictionary<string, object>. Only the Value is persisted — metadata like DisplayName, Category, and EditorHint are re-established during deserialization when the component's Initialize() method runs.

ToDto() — Serializing Components

public ComponentDto ComponentToDto(SkiaComponent component)
{
    var dto = new ComponentDto
    {
        Id = component.Id,
        TypeName = component.GetType().FullName,
        X = component.X,
        Y = component.Y,
        Width = component.Width,
        Height = component.Height,
        ZOrder = component.ZOrder,
        IsVisible = component.IsVisible
    };

    foreach (var kvp in component.NodeProperties)
    {
        dto.NodeProperties[kvp.Key] = kvp.Value.Value;
    }

    foreach (var port in component.InPoints)
    {
        dto.InPoints.Add(new ConnectionPointDto
        {
            Id = port.Id,
            PortType = "In",
            DataTypeName = port.DataType?.FullName,
            RowId = port.RowId,
            MaxConnections = port.MaxConnections
        });
    }

    foreach (var port in component.OutPoints)
    {
        dto.OutPoints.Add(new ConnectionPointDto
        {
            Id = port.Id,
            PortType = "Out",
            DataTypeName = port.DataType?.FullName,
            RowId = port.RowId,
            MaxConnections = port.MaxConnections
        });
    }

    return dto;
}

Connection Serialization

Connection lines are serialized by reference — they store the GUIDs of their start and end ConnectionPoint IDs rather than embedding the full port data. During deserialization, a GUID-to-port lookup index resolves these references:

ConnectionDto Structure

public class ConnectionDto
{
    public Guid Id { get; set; }
    public Guid StartPointId { get; set; }
    public Guid EndPointId { get; set; }

    public string LineStyle { get; set; } = "Solid";
    public string RoutingMode { get; set; } = "Straight";
    public string StartArrowhead { get; set; } = "None";
    public string EndArrowhead { get; set; } = "FilledTriangle";
    public float StrokeWidth { get; set; } = 2.0f;
    public string StrokeColor { get; set; }

    public string AnimationStyle { get; set; } = "None";
    public float AnimationSpeed { get; set; } = 1.0f;

    public string StartMultiplicity { get; set; }
    public string EndMultiplicity { get; set; }

    public float CornerRadius { get; set; }
    public float CurveTension { get; set; } = 0.5f;

    public List<LabelDto> Labels { get; set; } = new();
}

public class LabelDto
{
    public string Text { get; set; }
    public string Position { get; set; }
    public float OffsetX { get; set; }
    public float OffsetY { get; set; }
    public float FontSize { get; set; } = 12f;
    public string FontColor { get; set; }
    public string BackgroundColor { get; set; }
}

Line style properties are serialized as strings (enum names) for human-readable JSON. The deserializer parses these back to enum values using Enum.Parse() with case-insensitive matching.

Deserialization

Loading a diagram from JSON involves several coordinated steps to reconstruct the full object graph:

  1. Parse JSON: The JSON string is deserialized into a DiagramDto using System.Text.Json.
  2. Look Up Types: For each ComponentDto.TypeName, the SkiaComponentRegistry resolves the corresponding CLR type from its cache of scanned assemblies.
  3. Instantiate Components: Components are created via Activator.CreateInstance() and their Initialize() method is called. This re-establishes the NodeProperties dictionary with all metadata (DisplayName, Category, EditorHint).
  4. Restore Property Values: The saved values from ComponentDto.NodeProperties are applied to the freshly initialized dictionary.
  5. Build Port Index: All connection points across all components are indexed by GUID in a flat Dictionary<Guid, IConnectionPoint>.
  6. Restore Connections: For each ConnectionDto, the start and end ports are looked up in the GUID index and a new ConnectionLine is created with the saved style properties.
  7. Restore Viewport: ZoomFactor and PanOffset are restored from the ViewportDto.

LoadFromDto() — Deserialization Core Logic

public void LoadFromDto(DiagramDto dto)
{
    ClearCanvas();

    var portIndex = new Dictionary<Guid, IConnectionPoint>();

    foreach (var cDto in dto.Components)
    {
        var type = SkiaComponentRegistry.ResolveType(cDto.TypeName);
        if (type == null)
        {
            Logger.Warn($"Unknown component type: {cDto.TypeName}");
            continue;
        }

        var component = (SkiaComponent)Activator.CreateInstance(type);
        component.Initialize();

        component.Id = cDto.Id;
        component.X = cDto.X;
        component.Y = cDto.Y;
        component.Width = cDto.Width;
        component.Height = cDto.Height;
        component.ZOrder = cDto.ZOrder;
        component.IsVisible = cDto.IsVisible;

        foreach (var kvp in cDto.NodeProperties)
        {
            if (component.NodeProperties.TryGetValue(kvp.Key, out var param))
            {
                param.Value = kvp.Value;
            }
        }

        ApplyPortDtos(component, cDto.InPoints, ref portIndex);
        ApplyPortDtos(component, cDto.OutPoints, ref portIndex);

        AddComponent(component);
    }

    foreach (var connDto in dto.Connections)
    {
        if (!portIndex.TryGetValue(connDto.StartPointId, out var startPort))
            continue;
        if (!portIndex.TryGetValue(connDto.EndPointId, out var endPort))
            continue;

        var connection = Connect(startPort, endPort);
        ApplyConnectionDto(connection, connDto);
    }

    if (dto.Viewport != null)
    {
        ZoomFactor = dto.Viewport.Zoom;
        PanOffset = new SKPoint(dto.Viewport.PanX, dto.Viewport.PanY);
    }

    Invalidate();
}

Versioning

The SchemaVersion property in DiagramDto provides backward compatibility as the serialization format evolves:

VersionChangesCompatibility
"1.0"Initial format. Components serialized with position, size, and type name only.Legacy. Auto-upgraded to 3.0 on load.
"2.0"Added NodeProperties dictionary and ConnectionPointDto GUIDs.Supported. Minor props defaulted on load.
"3.0"Added Labels, AnimationStyle, Multiplicity, and Metadata. Added ViewportDto.Current. Full feature parity.

Version migration is handled transparently during LoadFromDto():

Version Migration

private DiagramDto MigrateDto(DiagramDto dto)
{
    if (dto.SchemaVersion == "1.0")
    {
        foreach (var c in dto.Components)
        {
            c.NodeProperties ??= new Dictionary<string, object>();
            c.InPoints ??= new List<ConnectionPointDto>();
            c.OutPoints ??= new List<ConnectionPointDto>();
        }
        dto.SchemaVersion = "3.0";
    }
    else if (dto.SchemaVersion == "2.0")
    {
        foreach (var conn in dto.Connections)
        {
            conn.Labels ??= new List<LabelDto>();
            conn.AnimationStyle ??= "None";
        }
        dto.Metadata ??= new Dictionary<string, string>();
        dto.SchemaVersion = "3.0";
    }

    return dto;
}

Note

Serialized files always use the latest SchemaVersion. The migration logic only executes when loading older files. This ensures that newly saved diagrams always use the current format.

Complete Save/Load Example

Below is a complete end-to-end example demonstrating saving a diagram to a file and loading it back:

Saving a Diagram

using System.Text.Json;

var drawingManager = new DrawingManager();
drawingManager.AttachCanvas(canvas);

var start = new FlowChartNode("Start");
start.X = 100; start.Y = 100;
drawingManager.AddComponent(start);

var process = new FlowChartNode("Process Data");
process.X = 400; process.Y = 100;
drawingManager.AddComponent(process);

var decision = new DecisionNode("Valid?");
decision.X = 250; decision.Y = 300;
drawingManager.AddComponent(decision);

drawingManager.Connect(start.OutPoints[0], process.InPoints[0]);
drawingManager.Connect(process.OutPoints[0], decision.InPoints[0]);

var dto = drawingManager.ToDto();
dto.Metadata["Author"] = "Jane Smith";
dto.Metadata["Description"] = "Order validation workflow";

var options = new JsonSerializerOptions
{
    WriteIndented = true,
    PropertyNamingPolicy = JsonNamingPolicy.CamelCase
};

string json = JsonSerializer.Serialize(dto, options);
File.WriteAllText("workflow_diagram.json", json);

Console.WriteLine($"Saved diagram with {dto.Components.Count} components " +
                  $"and {dto.Connections.Count} connections.");

Loading a Diagram

string json = File.ReadAllText("workflow_diagram.json");

var options = new JsonSerializerOptions
{
    PropertyNamingPolicy = JsonNamingPolicy.CamelCase
};

var dto = JsonSerializer.Deserialize<DiagramDto>(json, options);

var drawingManager = new DrawingManager();
drawingManager.AttachCanvas(canvas);

drawingManager.LoadFromDto(dto);

canvas.Invalidate();

Console.WriteLine($"Loaded: {drawingManager.Components.Count} components, " +
                  $"{drawingManager.Connections.Count} connections");
Console.WriteLine($"Viewport: zoom={drawingManager.ZoomFactor}, " +
                  $"pan=({drawingManager.PanOffset.X}, {drawingManager.PanOffset.Y})");

if (dto.Metadata.TryGetValue("Author", out var author))
{
    Console.WriteLine($"Diagram author: {author}");
}
