NuGet Installation

Beep.Skia is distributed as a set of NuGet packages. Install the core package to begin:

Install via .NET CLI

dotnet add package Beep.Skia

Install via Package Manager Console

Install-Package Beep.Skia

Additional packages are available for specialized functionality:

Package Description
Beep.Skia Core diagramming and rendering framework
Beep.Skia.Canvas Canvas controls and viewport management
Beep.Skia.Nodes Node types and specialized diagram elements
Beep.Skia.Connections Connection routing, ports, and pathfinding
Beep.Skia.Serialization JSON and binary diagram serialization

Project Setup

After installing the NuGet package, add the required using directives to your project:

Required Using Directives

using Beep.Skia;
using SkiaSharp;
using Beep\.Skia\.Components;
using Beep.Skia.Connections;
using SkiaSharp;

Configure your project file to target .NET 8 or .NET 9:

Project File Configuration

<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFramework>net8.0</TargetFramework>
    <Nullable>enable</Nullable>
    <ImplicitUsings>enable</ImplicitUsings>
  </PropertyGroup>
</Project>

Solution Structure

The Beep.Skia solution is organized into modular projects for separation of concerns:

Project Role
Beep.Skia Core framework and shared abstractions
Beep.Skia.Canvas Rendering surface, viewport, and interaction handling
Beep.Skia.Nodes Node model, rendering, and interaction logic
Beep.Skia.Connections Connection lines, routing algorithms, and ports
Beep.Skia.Serialization Diagram persistence and interchange formats
Beep.Skia.Theming Material Design 3.0 theme engine
Beep.Skia.Workflow Workflow automation and execution engine
Beep.Skia.Editor Visual diagram editor host and tooling

Verifying Installation

Confirm that Beep.Skia is correctly installed by running a minimal render test:

Verification Test

using Beep.Skia;
using Beep.Skia.Flowchart;
using SkiaSharp;

using var surface = SKSurface.Create(new SKImageInfo(800, 600));
var canvas = surface.Canvas;

var manager = new DrawingManager();
manager.AddComponent(new ProcessNode
{
    Label = "Hello Beep.Skia",
    X = 50, Y = 50, Width = 180, Height = 60
});

manager.Draw(canvas);
Console.WriteLine($"Canvas nodes: {manager.GetComponents().Count}");
Console.WriteLine("Beep.Skia installation verified successfully.");

If the code compiles and runs without errors, Beep.Skia is ready for development. For further guidance, proceed to the Quick Start Tutorial.
