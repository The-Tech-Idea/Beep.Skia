Display Components

Labels, SVG images and the minimap overview control

Display components render static or derived content: text labels, vector artwork and the minimap overview used by large diagrams.

SVG Image

Vector artwork rendered from SVG markup.

SvgImage

A component that displays SVG images with support for scaling and positioning.

MemberKindDescription
string SvgSourcePropertyGets or sets the SVG source. Can be a file path, embedded resource, or SVG content string. Supported formats: - File path: "C:\path\to\file.svg" or "relative\path\file.svg" - Embedded resource: "AssemblyName.ResourceName" (e.g., "Beep.Skia.svg.door.svg") - SVG content: Raw SVG XML string
SvgScaleMode ScaleModePropertyGets or sets the scaling mode for the SVG.
SKSize OriginalSizePropertyGets the original SVG size.

Minimap

Scaled overview of the diagram with a viewport rectangle.

MinimapControl

Diagram minimap: a scaled overview of all components and connection lines with a viewport rectangle showing the currently visible world area (from pan/zoom). Intended to be added as a static overlay component.
