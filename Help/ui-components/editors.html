Property Editors

NodePropertyEditor, ComponentPropertyEditor and the grid that backs them

Property editors render the editable surface for components and connection lines. They read NodeProperties and write values back through SetProperties, which is the same path used by serialization.

NodePropertyEditor

Visual property editor for automation nodes, similar to n8n/Make.com node configuration panels. Provides a comprehensive interface for editing node properties, data input, and configuration.
