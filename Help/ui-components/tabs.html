Tabs

Tabbed navigation with horizontal tab strip and content panels

Overview

The Tabs control provides tabbed navigation with a horizontal tab strip and associated content panels, rendered entirely with SkiaSharp. Each tab has a label, optional icon, and a content component that is shown when the tab is active. The active tab indicator is drawn as a 3px-thick underline that slides smoothly between tab positions using an animated transition.

The tab strip supports horizontal scrolling when the total tab width exceeds the control width, with fade indicators drawn at the edges when scrollable. Tab content is rendered directly within the control's body area below the strip.

Animated Indicator

The active-tab underline slides smoothly with a spring animation between tab positions.

Scrollable Tabs

When tabs overflow, horizontal scroll arrows appear and the strip becomes scrollable.

Icon Support

Each tab can display an SKPath icon above or beside its label text.

Content Hosting

Any SkiaComponent can be the content of a tab. Only the active tab's content is rendered.

Properties

PropertyTypeDescription
SelectedIndex int Zero-based index of the currently active tab. Setting this switches the visible content panel and moves the indicator. Default is 0.
TabItems List<TabItem> Collection of TabItem models defining the tabs. Each contains text, icon, and a content component reference.
TabPosition TabPosition Enum controlling tab strip placement: Top (default) or Bottom. Bottom-positioned tabs draw the indicator above instead of below.
Scrollable bool When true and tabs exceed the available width, horizontal scroll controls become visible. Default is true.
TabHeight float Height of the tab strip. Default is 48f.
IndicatorHeight float Thickness of the active-tab underline. Default is 3f.
ContentPadding float Padding around the content panel area. Default is 8f.
TabMinWidth float Minimum width per tab header. Default is 90f. Tabs with short labels still receive this minimum width.
TabMaxWidth float Maximum width per tab header. Default is 360f. Tabs grow to fill available space evenly up to this limit.

TabItem Model

The TabItem class defines a single tab in the tab strip. It is a model class (not a SkiaComponent) that holds the data the Tabs control uses for rendering.

PropertyTypeDescription
Text string Label displayed on the tab. Rendered using TitleSmall typography for inactive tabs and TitleSmall + Primary color for the active tab.
Icon SKPath Optional vector icon rendered above the text. When present, tab height expands to accommodate the icon. Icon color follows the same active/inactive state rules as text.
Content SkiaComponent The component displayed when this tab is active. Only one tab's content is drawn at a time. The content's coordinate space is relative to the content panel's top-left corner. Set to null for tabs that have no content.
IsEnabled bool When false, the tab appears dimmed and cannot be selected. Default is true.
Tag object Arbitrary data attached to the tab. Not rendered or serialized by default.
Badge string Optional badge text displayed as a small pill next to the tab label. Renderered in Error color on a small rounded background.

Events

EventSignatureDescription
SelectedIndexChanged EventHandler<int> Raised when the active tab changes. The integer argument is the new SelectedIndex. Raised after the indicator animation begins but before it completes.

Code Example

Basic Tabs with Multiple Content Panels

var tabs = new Tabs
{
    X = 20,
    Y = 20,
    Width = 600,
    Height = 400,
    SelectedIndex = 0,
    Scrollable = true
};
tabs.Initialize();

var generalContent = new Label
{
    Text = "General settings content goes here.",
    X = 0, Y = 0,
    Width = 580, Height = 300
};
generalContent.Initialize();

var appearanceContent = new Card
{
    Title = "Appearance",
    Subtitle = "Color theme and font settings",
    X = 0, Y = 0,
    Width = 580, Height = 300
};
appearanceContent.Initialize();

var advancedContent = new Label
{
    Text = "Advanced configuration options.",
    X = 0, Y = 0,
    Width = 580, Height = 300
};
advancedContent.Initialize();

tabs.TabItems.Add(new TabItem
{
    Text = "General",
    Content = generalContent
});

tabs.TabItems.Add(new TabItem
{
    Text = "Appearance",
    Content = appearanceContent
});

tabs.TabItems.Add(new TabItem
{
    Text = "Advanced",
    Content = advancedContent,
    IsEnabled = false
});

tabs.SelectedIndexChanged += (s, index) =>
    Console.WriteLine($"Tab switched to index {index}");

drawingManager.AddComponent(tabs);
canvas.Invalidate();

Tip

For dynamic tab content that changes at runtime, update the Content property of the relevant TabItem and invalidate the tabs control. The newly assigned component will be rendered on the next draw cycle without needing to recreate the tabs control.
