ComponentPalette

Toolbox/palette for drag-and-drop component discovery via SkiaComponentRegistry

Overview

The ComponentPalette control is a drag-and-drop toolbox that displays all registered SkiaComponent types as a categorized, searchable grid of icon+label tiles. It reads its inventory from the SkiaComponentRegistry — the centralized registry that maps component type metadata to factory delegates — enabling dynamic component discovery without hard-coded type lists.

Users can browse components by category, filter by keyword, select a display mode (icon grid or compact list), and drag items onto a canvas to instantiate new components. The palette renders entirely with SkiaSharp and follows Material Design 3.0 styling with elevation, state layers, and smooth drag-feedback animations.

Registry-Driven

Categories and items are populated automatically from SkiaComponentRegistry. No manual configuration required.

Search & Filter

A built-in search field filters components in real-time by name, description, or category tags.

Drag Ghost

Dragging a palette item creates a semi-transparent "ghost" preview that follows the pointer.

Custom Extensions

Register custom components and categories at runtime via the SkiaComponentRegistry API.

Component Discovery

The ComponentPalette discovers components exclusively through the SkiaComponentRegistry. This registry holds metadata for every component type available in the system, organized by category. The palette reads this data at initialization and builds its internal category/item structure.

SkiaComponentRegistry Entries

Each registry entry contains:

FieldTypeDescription
ComponentType Type The CLR type that implements the component. Must inherit from SkiaComponent.
DisplayName string Human-readable name shown in the palette tile (e.g., "Process Node", "Decision Diamond").
Description string Hover tooltip text describing the component's purpose. Also searched by FilterText.
Category string Grouping category (e.g., "Flowchart", "ERD", "Network", "UI Controls"). Components with the same category are grouped together in the palette.
Icon SKPath Vector icon drawn in each palette tile. Sized to fit within the tile with appropriate padding.
Factory Func<SkiaComponent> Delegate that creates a new instance of the component. The palette uses this for the drag-ghost preview and the canvas uses it when the drop is accepted.
DefaultWidth float Default width assigned to the component when dropped on the canvas. Default is 120f.
DefaultHeight float Default height assigned to the component when dropped on the canvas. Default is 60f.

How the Palette Reads the Registry

On initialization, the palette calls SkiaComponentRegistry.GetAllEntries() to retrieve a flat list of all registered component metadata. It then groups entries by Category, sorts categories alphabetically (with well-known diagram families listed first), and sorts entries within each category by DisplayName. The result is stored in the Categories property as a list of PaletteCategory objects.

The registry is read once during Initialize(). If components are registered after the palette is already displayed, call palette.Refresh() to re-read the registry and rebuild the category structure.

Drag-Drop Workflow

The drag-and-drop workflow is a multi-step interaction handled cooperatively by the palette, the InputManager, and the target canvas:

  1. Pointer Down on Tile: The palette identifies which PaletteEntry is under the pointer via hit testing.
  2. Drag Threshold: Once the pointer moves beyond a 4px threshold (while still pressed), the palette raises ComponentDragStarted. A drag ghost — a semi-transparent, scaled-down rendering of the component — is created and follows the pointer.
  3. Dragging Over Canvas: The InputManager enters drag mode. The canvas receives OnDragOver events with the pointer position. If the canvas supports component drops, it renders a drop indicator (a highlighted insertion point).
  4. Pointer Up: The palette raises ComponentDragEnded with a ComponentDropEventArgs containing the drop position and the PaletteEntry. The hosting application or canvas's drop handler creates a new instance via the entry's Factory delegate, sets its X/Y, calls Initialize(), and adds it to the drawing manager.
  5. Cancel: Pressing Escape during a drag cancels the operation. The ghost is removed and ComponentDragEnded fires with DropPosition = null.

Canvas-Side Drop Handler

palette.ComponentDragEnded += (s, args) =>
{
    if (args.DropPosition == null) return;

    var component = args.Entry.Factory();
    component.X = args.DropPosition.Value.X;
    component.Y = args.DropPosition.Value.Y;
    component.Width = args.Entry.DefaultWidth;
    component.Height = args.Entry.DefaultHeight;
    component.Initialize();

    drawingManager.AddComponent(component);
    canvas.Invalidate();
};

Custom Category Registration

Components are registered with the SkiaComponentRegistry using the static Register method. This is typically done at application startup before the palette is instantiated:

Registering Custom Components

SkiaComponentRegistry.Register(new ComponentRegistryEntry
{
    ComponentType = typeof(CustomGaugeNode),
    DisplayName = "Gauge",
    Description = "A custom gauge indicator with configurable range",
    Category = "Custom Widgets",
    Icon = SKPath.ParseSvgPathData(
        "M12 2C6.48 2 2 6.48 2 12s4.48 10 10 10 10-4.48 10-10S17.52 2 12 2z"),
    Factory = () => new CustomGaugeNode(),
    DefaultWidth = 100,
    DefaultHeight = 100
});

SkiaComponentRegistry.Register(new ComponentRegistryEntry
{
    ComponentType = typeof(StatusIndicator),
    DisplayName = "Status Indicator",
    Description = "Green/amber/red status dot with label",
    Category = "Custom Widgets",
    Icon = SKPath.ParseSvgPathData(
        "M12 2a10 10 0 1 0 0 20 10 10 0 0 0 0-20z"),
    Factory = () => new StatusIndicator(),
    DefaultWidth = 80,
    DefaultHeight = 30
});

Bulk Registering an Entire Assembly

SkiaComponentRegistry.ScanAssembly(typeof(MyCustomNode).Assembly);

The ScanAssembly method uses reflection to find all concrete types inheriting from SkiaComponent that are decorated with the [ComponentPaletteEntry] attribute. The attribute defines the display name, description, category, and icon path data:

Using the [ComponentPaletteEntry] Attribute

[ComponentPaletteEntry(
    DisplayName = "Pipeline Stage",
    Description = "An ETL pipeline stage node",
    Category = "ETL",
    IconPathData = "M20 2H4c-1.1 0-2 .9-2 2v16c0 1.1.9 2 2 2h16c1.1 0 2-.9 2-2V4c0-1.1-.9-2-2-2z",
    DefaultWidth = 140,
    DefaultHeight = 60
)]
public class PipelineStageNode : FlowChartNode
{
    public override void DrawContent(SKCanvas canvas)
    {
        base.DrawContent(canvas);
    }
}

Code Example

Basic ComponentPalette Setup

var palette = new ComponentPalette
{
    X = 10,
    Y = 50,
    Width = 320,
    Height = 600,
    DisplayMode = PaletteDisplayMode.Icons,
    TileSize = 68f,
    TilesPerRow = 4,
    ShowCategoryHeaders = true
};

palette.Initialize();

palette.FilterTextChanged += (s, filter) =>
    Console.WriteLine($"Filter: {filter}");

palette.ComponentDragStarted += (s, entry) =>
    Console.WriteLine($"Dragging: {entry.DisplayName}");

palette.ComponentDragEnded += (s, args) =>
{
    if (args.DropPosition == null)
    {
        Console.WriteLine("Drag cancelled");
        return;
    }

    var component = args.Entry.Factory();
    component.X = args.DropPosition.Value.X;
    component.Y = args.DropPosition.Value.Y;
    component.Width = args.Entry.DefaultWidth;
    component.Height = args.Entry.DefaultHeight;
    component.Initialize();

    drawingManager.AddComponent(component);
    canvas.Invalidate();
};

drawingManager.AddComponent(palette);
canvas.Invalidate();

Programmatic Filter and Category Control

palette.FilterText = "flow";

var allCategories = palette.ExpandedCategories;
palette.ExpandedCategories = new HashSet<string> { "Flowchart", "ETL" };

palette.DisplayMode = PaletteDisplayMode.List;

palette.CollapseAll();

palette.ExpandAll();

Refreshing After Runtime Registration

SkiaComponentRegistry.Register(new ComponentRegistryEntry
{
    ComponentType = typeof(DynamicChart),
    DisplayName = "Dynamic Chart",
    Category = "Runtime Components",
    Factory = () => new DynamicChart(),
    DefaultWidth = 200,
    DefaultHeight = 150
});

palette.Refresh();
canvas.Invalidate();

Note

The ComponentPalette is a read-only view of the registry. It does not modify or delete registry entries. If you need to remove a component from the palette, you must remove it from the SkiaComponentRegistry using SkiaComponentRegistry.Unregister(type) and then call palette.Refresh().

Tip

For large component libraries (50+ types), consider setting ShowCategoryHeaders = true and collapsing less-used categories by default. The palette renders only expanded categories, reducing visual clutter and improving rendering performance. Use ExpandedCategories to persist user preferences across sessions.
