# Beep.Skia.Wpf.Controls

WPF host controls for Beep.Skia components

| | |
|---|---|
| Target frameworks | `net10.0-windows10.0.19041.0` |
| NuGet package | `Beep.Skia.Wpf.Controls` |
| Documentation | [platforms.html](../Help/guides/platforms.html) |
| Start with | SkiaHost |

Targets net10.0-windows10.0.19041.0 because of SkiaSharp view assets.

```bash
dotnet add package Beep.Skia.Wpf.Controls
```

## Building

```bash
dotnet build Beep.Skia.Wpf.Controls/Beep.Skia.Wpf.Controls.csproj
```

The solution requires the private `TheTechIdea.Beep.*` NuGet feed; see [CONTRIBUTING.md](../CONTRIBUTING.md).
