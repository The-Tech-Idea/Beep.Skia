# Beep.Skia.UML

UML diagram components (class, component, deployment, sequence) with XMI export

| | |
|---|---|
| Target frameworks | `net8.0;net9.0` |
| NuGet package | `Beep.Skia.UML` |
| Documentation | [uml.html](../Help/diagram-families/uml.html) |
| Start with | UMLClass, UMLInterface, UMLInheritance, UMLMessage, XmiExporter |

Class, component, deployment, sequence and activity diagrams with XMI export.

```bash
dotnet add package Beep.Skia.UML
```

## Building

```bash
dotnet build Beep.Skia.UML/Beep.Skia.UML.csproj
```

The solution requires the private `TheTechIdea.Beep.*` NuGet feed; see [CONTRIBUTING.md](../CONTRIBUTING.md).
