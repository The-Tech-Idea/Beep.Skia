# Beep.Skia.StateMachine

State-machine diagram components (states, transitions, guards, regions) with validation

| | |
|---|---|
| Target frameworks | `net8.0;net9.0` |
| NuGet package | `Beep.Skia.StateMachine` |
| Documentation | [state-machine.html](../Help/diagram-families/state-machine.html) |
| Start with | StateNode, InitialStateNode, FinalStateNode |

Guards, entry/exit actions and transition semantics on the line.

```bash
dotnet add package Beep.Skia.StateMachine
```

## Building

```bash
dotnet build Beep.Skia.StateMachine/Beep.Skia.StateMachine.csproj
```

The solution requires the private `TheTechIdea.Beep.*` NuGet feed; see [CONTRIBUTING.md](../CONTRIBUTING.md).
