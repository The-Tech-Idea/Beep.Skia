# Beep.Skia.MindMap

Mind-map components (central topic, topics, sub-topics, notes) with radial layout, collapse and rich text

| | |
|---|---|
| Target frameworks | `net8.0;net9.0` |
| NuGet package | `Beep.Skia.MindMap` |
| Documentation | [mindmap.html](../Help/diagram-families/mindmap.html) |
| Start with | CentralNode, TopicNode, SubTopicNode, NoteNode |

Radial layout with collapse/expand.

```bash
dotnet add package Beep.Skia.MindMap
```

## Building

```bash
dotnet build Beep.Skia.MindMap/Beep.Skia.MindMap.csproj
```

The solution requires the private `TheTechIdea.Beep.*` NuGet feed; see [CONTRIBUTING.md](../CONTRIBUTING.md).
