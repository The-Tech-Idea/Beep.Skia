# Beep.Skia.DFD

Data Flow Diagram components (processes, data stores, external entities) with levelled drill-down and balancing validation

| | |
|---|---|
| Target frameworks | `net8.0;net9.0` |
| NuGet package | `Beep.Skia.DFD` |
| Documentation | [dfd.html](../Help/diagram-families/dfd.html) |
| Start with | ProcessNode, DataStoreNode, ExternalEntityNode, DFDLevelNavigator |

Gane-Sarson and Yourdon notation with level drill-down.

```bash
dotnet add package Beep.Skia.DFD
```

## Building

```bash
dotnet build Beep.Skia.DFD/Beep.Skia.DFD.csproj
```

The solution requires the private `TheTechIdea.Beep.*` NuGet feed; see [CONTRIBUTING.md](../CONTRIBUTING.md).
