# Beep.Skia.Winform.Controls

Windows Forms controls for Beep.Skia components - Design-time toolbox support

| | |
|---|---|
| Target frameworks | `net10.0-windows10.0.19041.0` |
| NuGet package | `Beep.Skia.Winform.Controls` |
| Documentation | [winforms.html](../Help/hosts/winforms.html) |
| Start with | SkiaHostControl, SkiaControl, SkiaButton, SkiaDataGrid |

A wrapper control for every Material component plus designers.

```bash
dotnet add package Beep.Skia.Winform.Controls
```

## Building

```bash
dotnet build Beep.Skia.Winform.Controls/Beep.Skia.Winform.Controls.csproj
```

The solution requires the private `TheTechIdea.Beep.*` NuGet feed; see [CONTRIBUTING.md](../CONTRIBUTING.md).
