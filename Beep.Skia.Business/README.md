# Beep.Skia.Business

Business process diagram components (BPMN pools, lanes, tasks, gateways) with BPMN 2.0 import and export

| | |
|---|---|
| Target frameworks | `net8.0;net9.0` |
| NuGet package | `Beep.Skia.Business` |
| Documentation | [business-process.html](../Help/diagram-families/business-process.html) |
| Start with | BusinessTask, Gateway, StartEvent, EndEvent, BpmnPoolNode, BpmnLaneNode |

BPMN import and export.

```bash
dotnet add package Beep.Skia.Business
```

## Building

```bash
dotnet build Beep.Skia.Business/Beep.Skia.Business.csproj
```

The solution requires the private `TheTechIdea.Beep.*` NuGet feed; see [CONTRIBUTING.md](../CONTRIBUTING.md).
