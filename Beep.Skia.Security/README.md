# Beep.Skia.Security

Security threat-modelling components with STRIDE analysis, DREAD scoring and MITRE ATT&amp;CK mapping

| | |
|---|---|
| Target frameworks | `net8.0;net9.0` |
| NuGet package | `Beep.Skia.Security` |
| Documentation | [security.html](../Help/diagram-families/security.html) |
| Start with | AssetNode, ThreatNode, ControlNode, StrideAnalyzer |

STRIDE analysis, DREAD scoring and MITRE technique mapping.

```bash
dotnet add package Beep.Skia.Security
```

## Building

```bash
dotnet build Beep.Skia.Security/Beep.Skia.Security.csproj
```

The solution requires the private `TheTechIdea.Beep.*` NuGet feed; see [CONTRIBUTING.md](../CONTRIBUTING.md).
