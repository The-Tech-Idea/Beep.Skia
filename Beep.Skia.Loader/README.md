# Beep.Skia.Loader

BeepDM plugin-loader integration that discovers Skia components in loaded assemblies

| | |
|---|---|
| Target frameworks | `net8.0;net9.0` |
| NuGet package | `Beep.Skia.Loader` |
| Documentation | [extensibility.html](../Help/guides/extensibility.html) |
| Start with | BeepSkiaLoaderExtensions |

BeepDM plugin-loader integration.

```bash
dotnet add package Beep.Skia.Loader
```

## Building

```bash
dotnet build Beep.Skia.Loader/Beep.Skia.Loader.csproj
```

The solution requires the private `TheTechIdea.Beep.*` NuGet feed; see [CONTRIBUTING.md](../CONTRIBUTING.md).
