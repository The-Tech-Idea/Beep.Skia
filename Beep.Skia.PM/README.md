# Beep.Skia.PM

Project-management diagram components (tasks, milestones, Gantt timelines) with critical-path calculation

| | |
|---|---|
| Target frameworks | `net8.0;net9.0` |
| NuGet package | `Beep.Skia.PM` |
| Documentation | [project-management.html](../Help/diagram-families/project-management.html) |
| Start with | TaskNode, MilestoneNode, GanttBarNode, GanttTimelineNode, CriticalPathNode |

Critical-path calculation and Gantt timelines.

```bash
dotnet add package Beep.Skia.PM
```

## Building

```bash
dotnet build Beep.Skia.PM/Beep.Skia.PM.csproj
```

The solution requires the private `TheTechIdea.Beep.*` NuGet feed; see [CONTRIBUTING.md](../CONTRIBUTING.md).
