# Beep.Skia.Network

Network topology diagram components with graph analysis (PageRank, shortest paths, communities)

| | |
|---|---|
| Target frameworks | `net8.0;net9.0` |
| NuGet package | `Beep.Skia.Network` |
| Documentation | [network.html](../Help/diagram-families/network.html) |
| Start with | NetworkNode, NetworkLink, NetworkGraph, PathFinder, CentralityMeasure |

Graph algorithms and community detection.

```bash
dotnet add package Beep.Skia.Network
```

## Building

```bash
dotnet build Beep.Skia.Network/Beep.Skia.Network.csproj
```

The solution requires the private `TheTechIdea.Beep.*` NuGet feed; see [CONTRIBUTING.md](../CONTRIBUTING.md).
