# Beep.Skia.WellLogs

Well-log components and LAS file parsing with multi-track grouping

| | |
|---|---|
| Target frameworks | `net8.0;net9.0` |
| NuGet package | `Beep.Skia.WellLogs` |
| Documentation | [welllogs.html](../Help/diagram-families/welllogs.html) |
| Start with | WellLogCanvas, WellLogRenderer, WellLogLayoutEngine, WellLogTemplates |

LAS 2.0/3.0 parsing with multi-track rendering.

```bash
dotnet add package Beep.Skia.WellLogs
```

## Building

```bash
dotnet build Beep.Skia.WellLogs/Beep.Skia.WellLogs.csproj
```

The solution requires the private `TheTechIdea.Beep.*` NuGet feed; see [CONTRIBUTING.md](../CONTRIBUTING.md).
