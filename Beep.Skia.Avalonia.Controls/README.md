# Beep.Skia.Avalonia.Controls

Avalonia host controls for Beep.Skia components

| | |
|---|---|
| Target frameworks | `net8.0` |
| NuGet package | `Beep.Skia.Avalonia.Controls` |
| Documentation | [platforms.html](../Help/guides/platforms.html) |
| Start with | SkiaCanvasControl |

Targets net8.0.

```bash
dotnet add package Beep.Skia.Avalonia.Controls
```

## Building

```bash
dotnet build Beep.Skia.Avalonia.Controls/Beep.Skia.Avalonia.Controls.csproj
```

The solution requires the private `TheTechIdea.Beep.*` NuGet feed; see [CONTRIBUTING.md](../CONTRIBUTING.md).
